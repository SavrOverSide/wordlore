# Wordlore

Telegram-бот про происхождение слов (RU/EN): слово дня, этимология, викторины. Каждое утро публикует слово дня в [@wordlores](https://t.me/wordlores).

- Бесплатно: `/word` и 3 викторины `/quiz` в день
- Премиум: 99 ⭐ Telegram Stars на 30 дней, безлимитные викторины и архив `/random`
- Владельцу: `/stats` (нужен `OWNER_ID` в `.env`)

Слова лежат в [lingvo/words.json](lingvo/words.json). Установка описана в [geekdigest](https://github.com/SavrOverSide/geekdigest#установка-на-сервер-все-три-проекта-сразу).
