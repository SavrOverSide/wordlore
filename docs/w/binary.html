Binary — позднелатинское binarius, «состоящий из двух», от bini, «по два». Двоичная система использует только две цифры, 0 и 1.

In English

Binary is Late Latin binarius 'consisting of two', from bini 'two each'. The binary system uses only two digits, 0 and 1.
