Cloud восходит к староанглийскому clūd, «скала, холм, глыба». Позже слово перенесли на облака из-за их сходства с нагромождением глыб. В IT облако рисовали на схемах сетей для обозначения «чего-то внешнего».

In English

Cloud goes back to Old English clūd 'rock, hill, mass of stone'. It was later applied to sky clouds because they look like piled-up masses. In IT, a cloud shape was drawn on network diagrams for 'someone else's network'.
