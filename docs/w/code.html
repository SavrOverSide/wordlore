Code — через старофранцузское code из латинского codex, исходно caudex, «ствол дерева, деревянная дощечка, книга». Кодексом называли свод законов, затем «код» стал шифром и программным текстом.

In English

Code came via Old French code from Latin codex, originally caudex 'tree trunk, wooden tablet, book'. A codex became a book of laws, then 'code' came to mean a cipher and program text.
