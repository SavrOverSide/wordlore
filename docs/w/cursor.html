Cursor — латинское cursor, «бегун, гонец», от currere, «бежать». Так называли движок на логарифмической линейке; затем — бегущую по экрану метку.

In English

Cursor is Latin cursor 'runner, courier', from currere 'to run'. It named the slider on a slide rule, and later the marker running across a screen.
