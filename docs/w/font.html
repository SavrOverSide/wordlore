Font — из среднефранцузского fonte, «отливка», от fondre, «плавить, отливать». Шрифтом сначала называли комплект литых металлических литер одного стиля.

In English

Font comes from Middle French fonte 'casting', from fondre 'to melt, cast'. A font was first a set of cast metal type of one style.
