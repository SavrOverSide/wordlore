Icon — греческое eikōn, «образ, подобие», через латинское icon. Религиозные иконы так назвали за изображение святых; значок на экране получил имя в 1970-х, в разработках Xerox.

In English

Icon is Greek eikōn 'likeness, image', via Latin icon. Religious icons got the name for depicting saints; the on-screen icon took the name in the 1970s from Xerox research.
