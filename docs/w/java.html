Java — название индонезийского острова, откуда в Европу везли кофе; так «java» стало разговорным словом для кофе в США. Язык программирования Java (1995) разработчики, по рассказам, назвали в честь кофе.

In English

Java is the name of the Indonesian island that exported coffee to Europe, so 'java' became American slang for coffee. The Java language (1995) was reportedly named by its developers after coffee.
