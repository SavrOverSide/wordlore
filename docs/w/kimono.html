Происхождение слова «кимоно»

Японский · 🌸 Дальний Восток

  1. ki + monoносить + вещь
  2. →
  3. kimonoвещь для ношения
  4. →
  5. кимоно

Японское кимоно составлено из ки, «носить», и моно, «вещь». Дословно это просто «вещь для носки», то есть одежда.

In English

Japanese ki 'wear' + mono 'thing' — literally 'a thing to wear', i.e. clothing.
