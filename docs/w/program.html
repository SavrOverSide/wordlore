Program — через латинское programma из греческого prographein, «писать заранее» (pro «перед» + graphein «писать»). Сначала это объявление или перечень событий, потом план действий компьютера.

In English

Program came via Latin programma from Greek prographein 'to write beforehand' (pro 'before' + graphein 'to write'). First a public notice or schedule, then a plan of computer actions.
