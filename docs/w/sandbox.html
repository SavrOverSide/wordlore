Sandbox — это sand «песок» и box «ящик»: так называли детскую песочницу. В программировании это изолированная среда, где код можно запускать без вреда для системы; в играх так зовут режим свободной игры.

In English

Sandbox is sand plus box: the children's play pit. In programming it is an isolated environment where code can run without harming the system; in games it names free-play modes.
