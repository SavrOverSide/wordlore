Server восходит к старофранцузскому servir и латинскому servire, «служить»; корень — servus, «раб». Сервер «обслуживает» запросы клиентов.

In English

Server goes back to Old French servir and Latin servire 'to serve', rooted in servus 'slave'. A server 'serves' client requests.
