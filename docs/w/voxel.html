Voxel образовано по аналогии с pixel: volume «объём» + pixel. Если пиксель — элемент плоской картинки, то воксель — элемент трёхмерного объёма.

Из каких слов составлено voxel?

  • vector + pixel (вектор + пиксель)
  • vertex + element (вершина + элемент)
  • volume + pixel
  • video + cell (видео + ячейка)
Показать ответ

volume + pixel. Пиксель с третьим измерением.

In English

Voxel is formed by analogy with pixel: volume plus pixel. If a pixel is an element of a flat image, a voxel is an element of a three-dimensional volume.
